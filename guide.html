Demo walkthrough

Try AccessPath.

Test the main workflow, then inspect how the interface and API work together.

Five-minute walkthrough

  1. Plan Main gate to Computer lab with Avoid stairs checked: 220 metres.
  2. Uncheck Avoid stairs and plan again: 170 metres.
  3. Restore Avoid stairs and close Lecture hall ↔ Computer lab.
  4. Plan again to see No route available, then reopen the segment.

Run and test

Start the app with python run.py. Run its automated checks with python -m unittest discover -v.

Data and limits

Locations and measurements are fictional. This demo cannot verify the safety or accessibility of a real route.

Records and closures persist in the local data directory. Restarting the app keeps your changes. Use a fresh --data-dir directory for a new synthetic demo.
